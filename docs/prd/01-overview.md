## 1. Overview

Build Skilient as a university-gated web network where Pakistani students prove skills through real project work, then turn that proof into a hiring signal. Pitch: "Join Pakistan's first social media platform exclusively for university students."

This PRD is the spec you would hand yourself to rebuild the product from an empty repo. Its reference build is the `social-layer` branch (head `fa7d78d`, Next.js 16 on React 19 + Supabase). The target is the full production platform plus its business model, not an MVP. That branch is only the starting point. Everything it merely promises is in scope: endorsements, contribution logs, verified CV, recruiter and teacher portals, live leaderboard and university dashboards.

- **In scope:** product requirements for every user type, business model and monetisation, data model, architecture, security, design system, production operations, build order.
- **Out of scope:** fundraising and pixel-level UI specs.
