## 2. Problem and users

Employers cannot verify what a Pakistani graduate can actually build, so hiring leans on CGPA and university prestige instead of demonstrated work. Talented students from lesser-known universities get overlooked while others overstate self-written CVs.

Skilient closes this trust gap with four layers, built in order:

1. **Identity trust** — accounts gated to a verified university email domain.
2. **Skill trust** — skills come from GitHub evidence, projects or endorsements, not a free-text field.
3. **Work trust** — project membership and contributions are recorded and immutable.
4. Outcome trust — recorded hires and the 90-day outcome check (5.20).

| User | Need | Served in reference build |
| --- | --- | --- |
| Student, first-year | Find teammates and a first project, build a track record | Yes |
| Student, final-year | Turn project history into a credible CV, get discovered | Partly (no CV export yet) |
| Admin / moderator | Keep the community safe, broadcast announcements | Yes |
| Teacher | Suggest project ideas, endorse and review student work | No |
| Recruiter | Search a verified talent pool by skill, university, rank | No |
| University admin | Analytics on student development beyond CGPA | No |

Success statement: a student from any Pakistani university, well-known or not, can build a project-backed profile and get discovered purely on the strength of real work.
