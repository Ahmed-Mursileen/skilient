### 5.9 Chat

> **Completed by 5.28.** Typing indicator, DM read receipts, replies, reactions, pins, search and thread types follow 5.28. Images are the only attachment type.

- `/chat` thread list with last message and unread count; `/chat/[threadId]` conversation.
- DMs are created lazily on the first Message action between friends; reuse an existing direct thread. Group threads belong to a venture.
- Realtime delivery via Supabase Realtime; show a visible "reconnecting" state on network loss.
- Messages: text up to 10,000 chars and/or one image (JPG, PNG, WebP, ≤ 5 MB). Sender can edit (shows "edited") and soft-delete. Failed sends render as failed.
- Opening a thread sets `last_read_at`; unread badges update live in the sidebar.

#### Build: chat

- **Routes:** `app/chat/layout.tsx` (thread list column on desktop), `chat/page.tsx`, `chat/[threadId]/page.tsx`.
- **Data:** `chat_threads(type, venture_id unique where type = 'group')`, `chat_thread_members(thread_id, user_id, last_read_at)` primary key both, `chat_messages(thread_id, created_at)` index.
- **RLS (fixes the reference build's hole):** select on all three tables only when `is_thread_member(thread_id, auth.uid())`; **no direct insert policy** on threads or members. Threads and memberships are created only by SQL functions: `get_or_create_dm(other)` (requires `are_friends` or an accepted application between the two, and no block; finds the existing DM via a unique `dm_key = least||greatest` column) and `decide_application` (group chats).
- **Send:** `sendMessage(threadId, body, mediaPath?)` → insert with RLS `with check (sender_id = auth.uid() and is_thread_member(...))`; body ≤ 10,000; one image (JPG/PNG/WebP ≤ 5 MB) from `chat-media/{thread_id}/{uuid}` (private bucket, read by members through signed URLs).
- **Edit/delete:** sender only, soft delete sets `deleted_at` and blanks the body server-side.
- **Realtime:** one channel per open thread (`postgres_changes` on `chat_messages` filtered by `thread_id`), plus presence for "reconnecting"; optimistic messages carry a client id, replaced by the server row; failed sends show Retry.
- **Unread:** `markThreadRead(threadId)` on open and on focus; list unread counts from a `thread_unread_counts` view.
- **Done when:** a non-member cannot read, join or post to a thread via direct API calls (tested with a raw Supabase client); DM creation between strangers is refused; messages arrive in ≤ 1 s p95.
